# 泥球大侠 · 最终需求摘要

游戏名：**泥球大侠**  
口号：小小泥球，也是大侠  
字体：全部中文用马善政楷书。  
引擎目标：Cocos Creator 3.8.x，微信小游戏。  
视觉：西部黄昏荒原、木质招牌、黄铜包边、金箔标题、羊皮纸面板。图4、图5 定风格，图1–3 定系统和玩法。

## 玩法核心

- 2D 俯视，玩家操控屎壳郎推动泥球前进。
- 目标：滚得更远、泥球更重，收集资源，避开或利用障碍与事件。
- 局内 HUD：金币、行进距离、泥球重量%、生命、暂停、小地图、虚拟摇杆、危险倒计时。
- 镜头：跟随泥球，略偏前进方向；左/右侧视角可选；不露地形边界。

## 地图系统（图1）

分层（由下到上）：天空 / 背景、地面、路径、障碍、收集物、装饰、特效、UI。

地块拼接顺序：起点 → 常规 → 奖励 → 陷阱 → 事件 → Boss / 终点。

路径宽度：

- 窄：2–3 格（危险）
- 标准：3–4 格
- 宽：4–6 格（奖励）
- 岔路：2–3 格

地图主题（后续）：荒漠、峡谷、火山谷、冰原、沼泽、古迹、矿坑铁路、墓园。  
第一期只做荒漠 / 荒原起点。

每张图有特色障碍。装饰要能辨认两侧：路径清晰、装饰成对、不挡可通行区域。

局内事件：触发区、定时机关、移动平台、护盾道具、加速带、危险箭头、陷阱、状态区。

## 局内物体（图2）

障碍：仙人掌、岩石、仙人掌群、地裂缝、沙坑、木箱、头骨、滚石、断木、路障木板、骷髅骨、流沙、火焰喷泉、尖刺陷阱、移动木桩、风沙、垮塌道路。

道具：加速靴、护盾、磁铁、体积增大、双倍金币、时间延长、无敌、清除障碍、能量恢复、泥土强化、喷射泥土、随机道具。

皮肤（后续）：初始、牛仔、黄金甲、机械甲、探险家、西部骑士、亡灵骑士、节日限定。

地图场景（后续）：荒漠起点、风蚀峡谷、仙人掌平原、干涸河道、废弃小镇、火山熔岩区、神祕遗迹、天空盐湖。

## 界面（图2、图4、图5）

首页：顶栏 签到 / 属性 / 排行榜 / 设置；金币板；中央大号「开始」木牌圆钮；角色与标题；商店入口。

加载页：标题、角色推球、进度条、西部黄昏背景、小提示文案。

功能图标：签到、属性、排行榜、设置、商店、皮肤、地图、成就、图鉴。均为木质方牌 + 简洁线标。

## 功能面板（图3，后续）

- 签到：连续 7 天，金币递增，第 7 天牛仔帽皮肤。
- 属性：推动力、移动速度、稳定性、初始重量、吸附范围；等级与经验。
- 排行榜：总量榜、最远距离榜、蜣螂大师榜。
- 设置：音乐、音效、震动、语言、画质、推送。
- 商店：推荐 / 道具 / 皮肤 / 金币；货币为金币。
