# 泥球的黄金回旋 · 第一期可玩核心

日期：2026-09-20  
引擎：Cocos Creator 3.8.8  
目标：微信小游戏，全程竖屏 750×1334

## 范围

首页 + 加载 + 一张荒原地图 + 摇杆推球 + 障碍/收集/距离结算。

不做：签到、属性养成、排行榜、商店内购、多皮肤、多地图、Boss。

## 视觉

- 图4、图5整图作为加载页、首页背景，可点区域做热区。
- 局内 HUD 竖屏：顶部金币/距离/重量/生命，底部摇杆。
- 西部黄昏：木牌、黄铜、金箔字、沙地暖色。

## 场景

单场景 `main`，运行时由 `GameApp` 切换 Loading / Home / Game / Result。

## 玩法

- 摇杆控制前进方向，蜣螂从后方推泥球。
- 前进为屏幕上方（+Y）。
- 吃金币加分，吃泥团加重，撞仙人掌扣生命。
- 生命为 0 或主动结束时弹出结算：距离、金币、重量。
